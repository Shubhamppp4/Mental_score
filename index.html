ABOUT MINDPULSE

Turning everyday patterns into insight.

MindPulse uses machine learning to estimate a wellbeing score from lifestyle and digital-behaviour patterns.

The project combines an interactive frontend with a FastAPI backend and a pre-trained machine learning model. It is designed as an educational AI project to explore how behavioural data can be transformed into meaningful digital wellbeing insights.
